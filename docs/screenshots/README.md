# App screenshots

These images show the main parts of ChromaPlay:

- `practice.jpg`: the visualizer, its resize handle, and playable harmonica.
- `score-editor.jpg`: the inline note editor, note colors, and line breaks.
- `backing-track.jpg`: the local audio upload and loaded file controls.
- `audio-timeline.png`: aligned notes and track waveforms with volume, start delays, and a shared playhead.

Capture these views as PNG or JPEG images from the running app using its default score or sample notation. Include the horizontal drag handle at the bottom of the visualization card in the practice view. Refresh the images after changing the interface, and check that labels remain readable in the main README. Keep private scores, personal filenames, and external music out of screenshots. A locally generated sample tone is enough when an audio file is needed to show the controls.
