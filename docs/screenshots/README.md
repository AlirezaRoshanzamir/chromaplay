# App screenshots

These images show the main parts of ChromaPlay:

- `practice.jpg`: the visualizer, its resize handle, and playable harmonica.
- `score-editor.jpg`: the inline note editor, editable tempo and time signature boxes, initial timing controls, note colors, and line breaks.
- `backing-track.jpg`: the short upload row below Notes, including a local file and its remove control.
- `audio-timeline.png`: matching Notes, Track, and Metronome waveform rows, independent volume and start delays, the metronome toggle, zoom, and a shared playhead.

Capture these views as PNG or JPEG images from the running app using its default score or sample notation. Include the horizontal drag handle at the bottom of the visualization card in the practice view. Refresh the images after changing the interface, and check that labels remain readable in the main README. Show playback beginning at zero; a negative start delay skips the part before zero instead of adding a lead-in. Keep private scores, personal filenames, and external music out of screenshots. A locally generated sample tone is enough when an audio file is needed to show the controls.
