A LITTLE LANGUAGE FOR MUSIC

From tab to melody.

Each note is a hole, a breath, and a length. That's it.

-3#q
drawholesliderlength
Tempo
Put TEMPO 90 on the first line. Use 30-300 quarter notes per minute. TEMP also works. Default: 60.
Time signature
Put TSIG 6/8 on the next line, before any notes. Default: 4/4. Either header is optional.
Breath
No sign or + to blow. - to draw.
Hole
1 through 12. Use 0 for a rest.
Slider
Add # after the hole to push the slider in.
Length
w whole, h half, q quarter, e eighth, s sixteenth.
Dotted notes
A final . adds half the length: 1q. is 1.5 beats.
Line breaks
Use uppercase L between notes to start a new row. Rows stay together; scroll sideways for long lines. It adds no time. Example: 1q -1q L 2h 0h.
Spacing
Spaces and new lines between notes are optional. Each header needs its own line. Use | to make bars easier to read; it adds no time.
